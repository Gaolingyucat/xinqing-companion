# 多模态情感预测与预警系统

这是一个基于 Flask 的基础项目骨架，用于后续扩展多模态情感预测、记录管理与预警报告功能。

## 目录结构

```text
emotion_warning_system/
├── run.py
├── config.py
├── requirements.txt
├── README.md
├── routes/
├── modules/
├── templates/
├── static/
├── data/
├── uploads/
└── reports/
```

## 启动方式

```bash
pip install -r requirements.txt
python run.py
```

启动后访问：

```text
http://127.0.0.1:5000
```
